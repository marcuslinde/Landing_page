# public/

Place static files here. Add images to the images/ subfolder.

- Upload images to: public/images/
- Reference them in the app as: /images/<filename>, e.g. `/images/billede1.webp`

Keep images in WebP format and sized for their display area (the page is
mobile-first). `public/` is copied verbatim into the build, so remove files
that are no longer used.
